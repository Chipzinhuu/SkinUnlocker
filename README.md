# 🎨 Among Us Skin Unlocker

A mod for **Among Us** that unlocks skins and cosmetics while providing additional gameplay customization features.

## ✨ Features

- 🔓 Unlock additional skins and cosmetics.
- 🎨 Customize your crewmate's appearance.
- 👕 Access different cosmetic options.
- 🚫 **Ban Points Removal:** Removes the penalty points received when leaving a game lobby.
- ⚙️ Simple and easy-to-use system.
- 🚀 Lightweight mod.

## 📋 Requirements

- Among Us (PC)
- [BepInEx](https://github.com/BepInEx/BepInEx)
- Compatible game version.

## 📥 Installation

1. Download the latest release.
2. Extract the downloaded files.
3. Move the mod files into your Among Us installation folder.
4. Launch the game.
5. Enjoy!
